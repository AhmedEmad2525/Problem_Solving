# SQL 50 Challenge Solutions

This folder contains my solutions to the **SQL 50 Challenge** on LeetCode. The SQL 50 Challenge is a comprehensive set of SQL problems designed to enhance proficiency in SQL queries, including basic to advanced concepts. Below is an overview of the contents:

---

## 📂 Content Overview

### 1. **File Structure**

- Each problem is saved with its corresponding number and name from the challenge for easy reference.
- SQL queries are structured for readability and efficiency.

### 2. **Topics Covered**

The challenge covers a variety of SQL concepts, including but not limited to:

- **Basic Queries**: SELECT, WHERE, ORDER BY
- **Joins**: INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL OUTER JOIN
- **Aggregation**: COUNT, SUM, AVG, MIN, MAX, GROUP BY, HAVING
- **Subqueries**: Correlated and non-correlated subqueries
- **Window Functions**: ROW\_NUMBER, RANK, DENSE\_RANK, NTILE
- **Set Operations**: UNION, INTERSECT, EXCEPT
- **Advanced Topics**: Common Table Expressions (CTEs), Recursive Queries, and more
